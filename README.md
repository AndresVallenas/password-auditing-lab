# Password Auditing Lab

## Objective

This project simulates an authorized internal password audit against
fictional Linux accounts created in an isolated laboratory.

## Tools

- John the Ripper
- Hashcat
- Kali Linux

## Methodology

1. Create fictional accounts.
2. Assign controlled laboratory passwords.
3. Generate or extract laboratory hashes.
4. Perform dictionary and rule-based audits.
5. Document recovered-password patterns.
6. Implement remediation.
7. Repeat the assessment.
